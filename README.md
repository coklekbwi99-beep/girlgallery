# Atelier Kayan — Katalog Karya

Situs katalog statis (HTML + CSS, tanpa PHP/database) — siap di-hosting gratis lewat GitHub Pages.

## Cara publish
1. Buat repository baru di GitHub (Public), misal `atelier-kayan`.
2. Upload file `index.html` ini ke repository (Add file > Upload files).
3. Buka Settings > Pages > pilih branch `main`, folder `/root` > Save.
4. Tunggu 1-2 menit, situs online di: `https://namakamu.github.io/atelier-kayan/`

## Catatan
- Gambar memakai layanan placeholder picsum.photos (eksternal), jadi tidak perlu upload folder gambar.
- Font memakai Google Fonts (Fraunces & Inter), dimuat otomatis dari CDN.
- Tombol "Lihat selengkapnya" saat ini mengarah ke jaringan iklan (effectivecpmnetwork.com).
  Ganti href-nya di index.html kalau ingin diarahkan ke halaman produk/kontak asli.
